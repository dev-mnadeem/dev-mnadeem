Full stack engineer based in Tallinn, Estonia. I work mostly in TypeScript (Node.js, NestJS, React, Next.js) and Python (Django, FastAPI), and I build applied AI features such as LLM assistants, retrieval and agents when they actually help the product.

**A few projects worth a look**

- [source-qa-explorer](https://github.com/dev-mnadeem/source-qa-explorer): ask questions about a GitHub repo and get answers cited to files and lines.
- [staff-roster-api](https://github.com/dev-mnadeem/staff-roster-api): staff scheduling API for a restaurant group across four sites and two time zones.
- [dental-visit-scheduling-bot](https://github.com/dev-mnadeem/dental-visit-scheduling-bot): chat assistant that books appointments and prevents double bookings.
- [mastra-mcp-workflow-demo](https://github.com/dev-mnadeem/mastra-mcp-workflow-demo): an MCP server, an agent that uses it, and a console that shows each tool call.
- [enterprise-planning-api](https://github.com/dev-mnadeem/enterprise-planning-api): backend for a cargo and logistics platform with role-based permissions.

- [kota-ai-assessment](https://github.com/dev-mnadeem/kota-ai-assessment): an ONS earnings-data pipeline with source provenance, atomic refresh, and a verified n8n orchestration workflow.
